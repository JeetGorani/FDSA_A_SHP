PRAC 3_a

Error: Sorting algorithms fail to run properly or overwrite original input data when passed the same array directly.

Solution: Create separate array copies (like `bubble`, `selection`, and `insertion`) before passing them to each sort function so original values stay intact.

PRAC 3_b

Error: Using binary search on an unsorted array returns incorrect indices or fails to find the target element.

Solution: Always sort the array using a sorting algorithm before performing a binary search on it.
